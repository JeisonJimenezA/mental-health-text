# This replaces a 159-package freeze of the virtual environment shared with
# the sibling audio experiment. That file recorded what happened to be
# installed rather than what this code imports, so it could not say which
# versions a result actually depended on. Every entry below is imported by
# something under src/, scripts/ or tests/; transitive dependencies are left
# to pip to resolve.
#

# exact versions, and the study reports single-seed runs: a change in a
# library default can move a number by as much as the arms differ from each
# other.
#
#   ..\env\Scripts\python.exe -m pip install -r requirements.txt
#
# torch is listed without a CUDA suffix. The logged runs used a CUDA build
# (2.11.0+cu128); install the wheel matching your driver from pytorch.org
# rather than taking the default here. Only the frozen-encoder and
# fine-tuning arms need a GPU -- the named-feature arms (E10-E15) are CPU
# only and run in minutes.
